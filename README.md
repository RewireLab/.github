# RewireLab

**Rebuild it. Benchmark it. Understand it.**

RewireLab is a collection of engineering projects focused on **rewriting, performance, systems, and experimentation**.

We build things to understand how they work — and sometimes to see how much better they can be built.

## What you’ll find here

**Rewrites**  
Implementing existing tools, libraries, and systems in different languages or architectures, with a focus on performance and simplicity.

**Systems**  
Networking, runtimes, databases, protocols, infrastructure, and other things that are interesting when you look underneath the abstraction.

**AI experiments**  
Small experiments with models, agents, inference, tooling, and new ways of building with AI.

**Benchmarks**  
Measuring real trade-offs instead of assuming one implementation is faster, smaller, or better.

## Why Rewire?

A lot of software is easy to use and hard to understand.

RewireLab is about going one layer deeper.

Read the source.  
Rebuild the idea.  
Measure the result.  
Learn something.

Not every project needs to become a product. Some projects are built simply because they are worth exploring.

---

### Projects

Repositories are generally built around one of three ideas:

`rewrite` · `experiment` · `benchmark`

Each project aims to be understandable on its own, reproducible, and useful for learning.
